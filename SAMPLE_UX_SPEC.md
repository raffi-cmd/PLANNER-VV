# UX SPECIFICATION: Planner V2

> Authoritative user journeys, screen flows, information architecture, and state feelings.

---

## 1. USER JOURNEY & CORE ACTIONS

### Primary User Flow
1. **Idea Ingestion**: Enter project brief or idea.
2. **Plan Synthesis**: Synthesize Product, UX, and Technical architecture graph.
3. **Design Intent Configuration**: Establish Design North Star, Visual Metaphor, References, and Anti-Patterns.
4. **Export & Handoff**: Generate `HANDOFF.md`, `DESIGN_BRIEF.md`, and `UX_SPEC.md` for AI coding agents.

---

## 2. UX STATE FEELINGS & BEHAVIORAL GUIDELINES

- **First Visit / Onboarding State**:
  - Uncluttered introduction; immediate single CTA leading to value.
- **Empty State**:
  - Quiet, instructional, and actionable. Zero decorative empty illustration clichés.
- **Input & Editing State**:
  - Real-time inline feedback; accessible, visible keyboard focus rings.
- **Loading & Processing State**:
  - Context-aware skeleton loaders without layout shift.
- **Success & Completion State**:
  - Instant inline confirmation; unambiguous status update without disruptive modals.
- **Error & Recovery State**:
  - Explicit root-cause message with inline retry/recovery options.
- **Mobile Viewport State**:
  - Single-column stacked workflow preserving visual hierarchy; min touch target 44x44px.
